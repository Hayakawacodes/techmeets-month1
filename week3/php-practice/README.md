# コメント投稿フォームの修正（実践課題）

## ファイル
- comment.php：修正前のコード
- comment_fixed.php：修正後のコード

## 見つけた問題点
1. if ($name = "")は代入であるため、名前が消えて表示される
2. XSS対策として、htmlspecialcharsが使われていない
3. 空のコメントでも投稿できてしまう

## 修正した内容
if ($name == "")に変えることで、名前も表示されるようになった
htmlspecialcharsで変換してから表示した
$comment にも空チェックを追加した
## 学んだこと
＝の数だけでも意味が異なるため、注意が必要である
XSS対策を忘れてわならない
空の状態で表示してしまわないように、空チェックを追加しているか確認する
