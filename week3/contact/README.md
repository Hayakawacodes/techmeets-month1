# お問い合わせフォーム

## 概要
PHPで作成したお問い合わせフォームです。
1つのファイル（contact.php）で、入力画面と確認画面を切り替えて表示します。

- 入力項目：名前、メールアドレス、件名、メッセージ
- 全項目必須で、メールアドレスは形式もチェックする
- htmlspecialcharsでXSS対策をしている
- 入力に問題がなければ、確認画面に入力内容を表示する

## 動作確認方法
VS Codeで contact.php を右クリックし、「PHP Server: Serve project」で開く

## 工夫した点
- エラーがあったとき、入力した内容が消えないようにした
- trimを使い、スペースだけの入力もエラーになるようにした
- empty()ではなく `=== ''` で判定し、「0」と入力してもエラーにならないようにした

## 学んだこと
- XSS対策として、htmlspecialcharsを使う
- Claude Codeが作ったコードも、自分で読んで理解し、確認することが大切だということ
